## 남은 사항과 범위

- 실제 사용 중인 휴대폰·태블릿의 저장소나 스피커는 원격으로 직접 검사하지 않았다. 로컬 검증은 별도 출처의 합성 기록으로 수행한다. 각 기기 기존 앱/주소의 기록은 유지되며, 서로 다른 기기 간 공유에는 기존 연동 설정이 필요하다.
- 앱 업데이트는 기존 서비스 워커의 안전한 화면 전환 시점에 적용된다. 실행 중인 공부를 강제로 새로고침하지 않는다. 오프라인 기기는 인터넷 연결 후 받는다.
- 기존 PNG 원본 6개가 잘려 있다. 배포된 WebP는 정상이며 대체 표시를 유지한다. 기존 그림 교체 금지에 따라 원본을 덮어쓰지 않았다. 도서관 수정 후보는 별도 로컬 파일로만 보관한다.
- 일부 옆모습 액세서리의 동작별 위치는 추가 검수 대상이다. 나비·씨앗·비눗방울은 새 원본/배포 파일 3개로 보완했다. 기존 잘린 시트를 수정한 것은 아니다.
- `꽃`은 현재 받침 교육 범위에 없는 ㅊ 때문에 미학습 필터로 제외된다. 학습 순서/통과 규칙을 임의로 바꾸지 않았다. 받침 범위 확장은 별도 교육과정 변경안이 필요하다.
- 이번 개선은 기존 기능 보존과 확인된 오류·누락에 한정한다. 전면 UI 재설계, 학습량 변경, 신규 대규모 기능은 포함하지 않는다.
