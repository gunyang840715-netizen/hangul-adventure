## 남은 사항과 범위

- 실제 사용 중인 휴대폰·태블릿의 저장소나 스피커는 원격으로 직접 검사하지 않았다. 로컬 검증은 별도 출처의 합성 기록으로 수행한다. 각 기기 기존 앱/주소의 기록은 유지되며, 서로 다른 기기 간 공유에는 기존 연동 설정이 필요하다.
- 앱 업데이트는 기존 서비스 워커의 안전한 화면 전환 시점에 적용된다. 실행 중인 공부를 강제로 새로고침하지 않는다. 오프라인 기기는 인터넷 연결 후 받는다.
- 기존 PNG 원본 6개가 잘려 있다. 배포된 WebP는 정상이며 대체 표시를 유지한다. 기존 그림 교체 금지에 따라 원본을 덮어쓰지 않았다. 도서관 수정 후보는 별도 로컬 파일로만 보관한다.
- 일부 옆모습 액세서리의 동작별 위치, 나비·씨앗·비눗방울 효과 원화는 추가 검수/제작 대상이다. 구현 완료로 표시하지 않는다.
- `꽃`은 현재 받침 교육 범위에 없는 ㅊ 때문에 미학습 필터로 제외된다. 학습 순서/통과 규칙을 임의로 바꾸지 않았다. 받침 범위 확장은 별도 교육과정 변경안이 필요하다.
- 이번 개선은 기존 기능 보존과 확인된 오류·누락에 한정한다. 전면 UI 재설계, 학습량 변경, 신규 대규모 기능은 포함하지 않는다.

## 10월 16일 추가 개선

- **백업 불러오기 보호:** 버전 번호만 있는 불완전 JSON도 초기 상태로 보완되어 기존 진도를 덮어쓸 수 있었다. 불러오기 직전에 필수 구조와 제공된 필드의 자료형을 검사한다. 22종 손상 백업은 메모리·저장소를 바꾸지 않고 거절한다. v1/v2/v3 복원과 첫 학습의 `last=-1` 표식을 검증했다. 평소 앱 실행·연동·저장 형식에는 이 검사를 적용하지 않아 기존 기록을 바꾸지 않는다.
- **보리 먹기 꾸미기:** 기존 프레임을 그대로 사용한다. 머리를 직접 찾지 못한 한 칸을 검증된 이웃 칸을 경유해 추적하고 기존 상관·실루엣 기준으로 재검증했다. 기존 모든 친구/동작 좌표를 보존하고 보리 먹기 4칸만 추가했다. 실제 앱과 미리보기에서 모자·안경·목걸이·옷을 확인했다.
- **꾸미기 처리 도구:** `ART_SIDE_MOTIONS=eat`처럼 동작을 지정하면 기존에 검수한 다른 동작 좌표를 유지한다. 좌표 검사에서 10마리·66동작·334프레임의 수·숫자·변환을 확인했다.
