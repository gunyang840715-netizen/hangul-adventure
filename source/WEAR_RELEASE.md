# 대표 캐릭터 착용 개선 — 2026-10-17

기존 캐릭터와 학습 기록을 유지하면서 식빵(corgi)의 줄무늬 옷, 밀짚모자, 동그란 안경, 목도리, 운동화를 자세별 실제 착용 원화에서 분리한 부품으로 표시한다.

- 적용: 정면 1칸, 서기 4칸, 걷기 8칸, 앉기 전환 4칸, 먹기 4칸, 엎드리기/잠 4칸. 해당 다섯 아이템의 부분 착용 조합도 지원한다.
- 원래 캐릭터의 얼굴·몸 그림을 유지한다. 안경 렌즈는 투명하게, 의복은 몸 윤곽에 맞게, 신발은 보이는 발마다 연결했다.
- 기기에서는 격자를 계산하지 않는다. 신규 투명 WebP 5장을 필요한 캐릭터/아이템에서만 받아 재사용한다. 기존 서비스워커의 지연 다운로드·오프라인 저장 경로를 사용한다.
- 다른 친구, 다른 아이템과 섞은 조합, 달리기·긁기 등 미검수 동작은 기존 표시를 사용한다. 이를 전체 아이템 개선 완료로 보지 않는다.
- 다운로드 실패/받는 중에도 기존 캐릭터와 착용 선택을 유지한다. 아이템 ID, 학습 기록, 보상, 연동 구조, 앱 주소, 설치 식별자는 바꾸지 않는다.

검증: 필수 학습·이어하기·연동·보상·음성·오프라인·자산 검사 통과. 새 렌더러 775개 비어 있지 않은 조합/자세와 미지원/로딩 실패 검사 통과. 브라우저 앱용 WebP 32조합×25칸=800회에서 눈·코·입 주변 보존과 벗기기 후 원본 RGBA 복원 통과. 실제 Pet 컴포넌트로 데스크톱/휴대폰 크기 화면의 착탈·정면·서기·걷기·앉기 확인.

실제 Android/iPad 기기의 성능·음성·설치 앱 자동 수신은 원격으로 확인하지 못했다. 전체 아이템 시각 검수 장부는 별도이며 완료 처리하지 않았다.
