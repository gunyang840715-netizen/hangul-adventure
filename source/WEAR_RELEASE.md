# 대표 캐릭터 착용 개선 — 2026-10-17

기존 캐릭터와 학습 기록을 유지하면서 식빵(corgi)의 줄무늬 옷, 밀짚모자, 동그란 안경, 목도리, 운동화를 자세별 실제 착용 원화에서 분리한 부품으로 표시한다.

- 적용: 정면 1칸, 서기 4칸, 걷기 8칸, 앉기 전환 4칸, 먹기 4칸, 엎드리기/잠 4칸. 해당 다섯 아이템의 부분 착용 조합도 지원한다.
- 원래 캐릭터의 얼굴·몸 그림을 유지한다. 안경 렌즈는 투명하게, 의복은 몸 윤곽에 맞게, 신발은 보이는 발마다 연결했다.
- 기기에서는 격자를 계산하지 않는다. 신규 투명 WebP 5장을 필요한 캐릭터/아이템에서만 받아 재사용한다. 기존 서비스워커의 지연 다운로드·오프라인 저장 경로를 사용한다.
- 다른 아이템과 섞어도 검수된 부품은 계속 적용하고, 아직 검수하지 않은 아이템만 기존 표시로 그린다. 다른 친구와 달리기·긁기 등 미검수 동작은 기존 표시를 사용한다. 이를 전체 아이템 개선 완료로 보지 않는다.
- 다운로드 실패/받는 중에도 기존 캐릭터와 착용 선택을 유지한다. 아이템 ID, 학습 기록, 보상, 연동 구조, 앱 주소, 설치 식별자는 바꾸지 않는다.

검증: 필수 학습·이어하기·연동·보상·음성·오프라인·자산 검사 통과. 새 렌더러 775개 비어 있지 않은 조합/자세와 미지원/로딩 실패 검사 통과. 브라우저 앱용 WebP 32조합×25칸=800회에서 눈·코·입 주변 보존과 벗기기 후 원본 RGBA 복원 통과. 실제 Pet 컴포넌트로 데스크톱/휴대폰 크기 화면의 착탈·정면·서기·걷기·앉기 확인.

실제 Android/iPad 기기의 성능·음성·설치 앱 자동 수신은 원격으로 확인하지 못했다. 전체 아이템 시각 검수 장부는 별도이며 완료 처리하지 않았다.

## 혼합 착용 보완

- 아이템 하나를 바꾸거나 그림 하나를 받지 못했을 때 다른 개선 부품까지 이전 표시로 돌아가던 조건을 아이템별 준비 상태로 바꿨다.
- 정면에서는 원래 몸/머리 변환을 따르는 같은 좌표계 안에 새 부품과 기존 부품을 순서대로 넣는다. 동작 프레임도 옷→신발→목걸이→모자→안경 순서를 유지한다.
- 기존 목걸이를 턱 뒤에 놓을 때 새 옷·신발을 다시 원본으로 지우지 않도록 가림 영역으로 처리한다.
- 자동 검사: 800개 혼합 조합/자세의 부품 유지 및 다른 아이템으로 잘못 대체하는 문제 방지, 실제 Pet 정면 32개 혼합 조합의 중복·누락 검사 통과. 왕관/나비넥타이와 기존 개선 부품의 조합을 검수 화면에서 확인한다.
- 그림 파일·아이템 ID·저장 형식은 추가로 바꾸지 않았다. 개별 부품의 표시가 바뀔 때만 DOM 가림 상태를 갱신한다.

- 필수 검사와 기존 렌더러/혼합 검사, 추가 800개 변형 조합 검사 통과. 브라우저에서 원화 합성 800회, 최종 WebP 1,600회 얼굴 보존·벗김 원본 RGBA 복원, 실제 Pet 정면 64개 혼합 조합의 중복·누락 검사 통과. 25칸의 목끈·매듭·턱/발 가림을 개별 시각 검수하고 휴대폰/태블릿 크기의 실제 Pet 표시를 확인했다.
- 이번 추가는 코기 나비넥타이와 위 25칸에 한정한다. 다른 친구, 달리기·점프·긁기 등 추가 동작, 나머지 아이템의 실제 착용 개선과 실기기 검수는 남아 있다. 전체 시각 검수 장부는 완료 처리하지 않았다.

## 고양이 다섯 친구 방울 목걸이 정면 연결

- 기존 방울 목걸이 원화를 뒤목끈과 앞목끈·방울로 나누고 냥이·다랑이·꽁치·모찌·솜사탕의 실제 목둘레에 따로 맞췄다. 뒤끈은 몸 뒤로, 앞끈은 원래 턱털 뒤로 가려 목에 닿도록 했다. 각 친구의 원래 얼굴·턱털·발과 벗긴 모습을 보존하며 냥이 원피스와의 동시 착용도 확인했다.
- 다섯 WebP 합계는 31,864바이트로 기존 마리당 2.5MB·전체 60MB 상한을 유지한다. 각 친구 정면 한 칸에 한정하고 기존 옷·모자와 다른 친구의 모든 좌표를 보존한다. 다른 자세·품목·실제 기기 검수는 남아 있다.


## 뭉치 달리기 여섯 칸 야구모자

- 검수한 걷기 모자의 실제 부품을 그대로 재사용하고 달리기 여섯 칸의 머리 크기·기울기·위치에 각각 등록했다. 각 칸의 머리 접촉·챙·실제 귀 전체를 따로 확인하며 얼굴·몸·발과 기존 귀 보호핵, 벗긴 모습을 보존한다.
- 추가 이미지와 재인코딩은 없고 기존 정면 1칸·서기 4칸·걷기 8칸을 보존한다. 야구모자 지원은 총 19칸이며 해당 파일 미수신 시 기존 표시로 돌아간다. 다른 동작·품목·실제 기기 검수는 남아 있다.


## 뭉치 점프 여섯 칸 야구모자

- 걷기 모자의 실제 부품을 추가 이미지 없이 점프 여섯 칸의 머리 크기·기울기·위치에 따로 맞췄다. 웅크림부터 도약·공중·착지까지 각 칸의 머리 접촉·챙·실제 귀 전체를 확인하고 원래 얼굴·몸·발과 벗긴 모습을 보존한다.
- 기존 정면·서기·걷기·달리기 19칸과 다른 모든 등록을 보존하며 야구모자 지원은 총 25칸이다. 추가 그림·재인코딩·용량 증가는 없고 같은 세 파일만 사용한다. 다른 동작·품목·실제 기기 검수는 남아 있다.


## 다랑이·꽁치·모찌·솜사탕 원피스 정면 연결

- 기존 원피스 원화에서 몸판과 실제 어깨 소매를 분리해 각 친구의 목 구멍·팔·네 발에 맞췄다. 목 안감은 털 뒤로 가리고 소매는 원래 앞다리와 연결한다. 각 친구 단독 및 방울 목걸이 동시 착용, 얼굴·턱털·발 보존과 벗긴 모습을 따로 확인했다.
- 네 WebP 합계는 111,170바이트로 기존 마리당 2.5MB·전체 60MB 상한을 유지한다. 각 친구 정면 한 칸만 연결하며 냥이 원피스 25칸·기존 목걸이·모자·다른 모든 등록을 보존한다. 다른 자세·품목·실제 기기 검수는 남아 있다.
