(연결 폴더: 바탕화면\hangul\integrated-app — source가 아니라 그 위 폴더)

너는 이 저장소의 코드·통합·검사·배포 담당이다. 그림 담당은 GPT다.

1. 연결된 폴더에서 git status → AGENTS.md, COLLAB.md, HANDOFF.md를 읽어라(COLLAB.md 4장 순서대로).
2. art-src/GPT_진행.md와 각 묶음의 납품.md로 GPT가 그린 것을 확인하라. ChatGPT 채팅으로 받은 그림(art-src/<묶음>/받은그림/)이 있으면
   주문서 순서와 그림을 보고 file 이름을 맞춰라.
3. 납품된 묶음부터: 규격 검사(크기·여백·투명·색감·7-4 표와 일치) → 불합격은 HANDOFF '다시 그릴 것'에
   → 합격분 후처리(자르기·배경 지우기·가장자리 색 번짐 제거·크기·WebP·해시) → artmap·manifest → 코드
   → npm run check → 화면 확인(?demo=1, 콘솔 오류 0) → 커밋(art/ 먼저, 그다음 source/) → push → Actions 결과 확인.
4. 묶음마다 미리보기(캐릭터는 GIF)를 대화에 보여 줘. HANDOFF를 갱신·커밋·push하고 폴더를 main에 맞춰라.
5. 한도에 걸리면 검사를 통과한 것만 커밋·push하고, 나머지는 HANDOFF '진행 중 변경'에 남겨라.

되돌릴 수 없는 일만 묻고 나머지는 진행해. 설명은 한국어로 짧게. 아이·가족 이름은 코드·파일·커밋 어디에도 쓰지 마.
