[한글나라 · 그림 담당 GPT — 클라우드 시작 문구 (컴퓨터가 꺼져 있어도 계속)]
ChatGPT(웹·폰·데스크톱 어디서든) 새 대화에 아래 '붙여 넣을 말'만 보내면 된다.
자세한 규칙은 구글 드라이브 「한글나라 그림 작업 (GPT·Claude 공용)」 폴더의 '00 작업지시'(Claude가 관리, 판 번호가 가장 큰 것)를 GPT가 직접 읽는다.
규칙이 바뀌면 Claude가 드라이브에 새 판(v2, v3…)을 올리므로, 이 문구는 다시 보낼 필요가 없다(매시간 예약 실행이 최신판을 읽음).

■ 붙여 넣을 말
[한글나라 그림 · 클라우드 이어하기]
구글 드라이브 「한글나라 그림 작업 (GPT·Claude 공용)」 폴더의 '00 작업지시'(판 번호가 가장 큰 것)를 읽고 그대로 이어서 그림 작업을 해.
컴퓨터는 꺼져 있어도 된다. 바탕화면 폴더·로컬 Codex·git은 쓰지 말고, 재료는 그 드라이브 폴더에서 읽고 결과는 그 폴더의 '결과'에 올려.
처음부터 다시 하지 말고 완료목록의 '다음 작업'부터. 매시간 자동 이어하기 예약도 작업지시 6번대로 다시 켜(예전 예약은 끄고 하나만).
질문하지 말고 끝까지. 설명은 한국어로 짧게.

■ 드라이브 폴더 구성 (Claude가 만들어 둠)
- 00 작업지시 vN … : GPT가 매번 먼저 읽는 규칙(아래 사본과 같음)
- 01 완료목록 … : 끝난 작업·다음 작업 (GPT는 결과/에 '완료목록-<시각>.txt'를 새로 더함)
- 재료/ : 재료1-주문서-기준표-참고사진.zip · 재료2-정본-말티즈-냥이-초코.zip · 재료3-정본-식빵-보리-콩이.zip · 재료4-정본-구름-앞부분.zip
          (컴퓨터의 art-src/_클라우드전달/에 있는 zip 4개 — 사용자가 끌어다 놓거나 Claude가 올림)
- 결과/ : GPT가 만든 그림 zip과 완료목록

■ (참고) 00 작업지시 v1 사본 — 드라이브 문서가 기준
[한글나라 · 그림 담당 GPT — 클라우드 작업지시 v1] 2026-10-13 · Claude 작성

이 문서는 Claude가 관리한다. 바뀌면 같은 폴더에 v2, v3…으로 새 판을 올린다.
→ 매번 시작할 때 '00 작업지시'로 시작하는 문서 중 판 번호가 가장 큰 것을 읽는다.
그림의 기준은 사용자 원문·추가 요청이다(주문서마다 '사용자_원문'·'사용자_추가_요청'에 그대로 들어 있음). 이 문서·주문서가 원문과 다르면 원문을 따른다.

0. 지금 상황
- 사용자 컴퓨터는 꺼져 있을 수 있다. 바탕화면 integrated-app 폴더·로컬 Codex·git은 쓰지 않는다. 재료는 이 구글 드라이브 폴더에서 읽고, 결과는 이 폴더에 올린다.
- 처음부터 다시 하지 않는다. 끝난 그림은 건너뛰고 '01 완료목록'(또는 결과/ 폴더의 더 새로운 완료목록)의 '다음 작업'부터 이어 간다.
- 이미지는 ChatGPT 내장 이미지 생성으로만 만든다. OPENAI_API_KEY 같은 유료 API는 쓰지 않는다(돈이 나감).

1. 이 폴더 「한글나라 그림 작업 (GPT·Claude 공용)」
- 00 작업지시 vN: 이 문서
- 01 완료목록 …: 끝난 작업·다음 작업(Claude가 만든 것). 결과/에 네가 올린 '완료목록-…'이 더 새로우면 그것이 기준.
- 재료/ (Claude·사용자가 올림. 고치지 않는다)
  · 재료1-주문서-기준표-참고사진.zip → art-src/주문서/0-style.json~9-words.json, art-src/style/style-guide.png, art-src/참고사진/원본/<id>.jpg(사용자 사진, 원문대로 우선), art-src/참고사진/heads/<id>.png
  · 재료2-정본-말티즈-냥이-초코.zip, 재료3-정본-식빵-보리-콩이.zip → art-src/1-pets/<id>-full.png, <id>-model.png (이미 앱에 들어간 정본 — 2순위 동작의 참고)
  · 재료4-정본-구름-앞부분.zip → art-src/1-pets/russian-full.png, russian-eyes-closed.png, russian-mouth-open.png (순번 80~82 정본 — 83~92의 원본·참고)
  · zip 안의 경로는 주문서의 '참고'·'원본' 경로와 같다. 압축을 풀어 그대로 쓴다.
- 결과/: 네가 만든 그림(zip)과 완료목록을 올리는 곳

※ 재료 zip이 아직 없으면(올라오기 전): 내 드라이브 맨 위의 '한글나라 그림 클라우드 이어하기 2026-10-13.zip'(주문서·기준표·참고사진·1-pets 1~39가 들어 있음)을 대신 쓴다.
  재료4가 없으면 구름(russian)은 80번(russian-full)부터 다시 만들고 그것을 정본으로 한다.
  재료3이 없으면 식빵·보리·콩이의 2순위 동작은 건너뛰고 완료목록에 '보류'로 적는다(재료3이 올라오면 그때 한다).

2. 시작할 때마다 (예약 실행 포함)
 a) 최신 '00 작업지시' → 최신 완료목록 → 필요한 재료 zip 순서로 연다.
 b) 다음 작업 = 주문서 순서(0-style → 1-pets → 2-items → 3-snacks → 4-bg → 5-room → 6-yard → 7-park → 8-build → 9-words, 각 주문서 '작업' 목록 위→아래) 중 완료목록에 없는 첫 작업. 단 이 문서 7장 '다시 그릴 것'이 있으면 그것부터.
 c) 앞 작업의 결과가 '원본'·'참고'로 필요하면(예: 83번 russian-body는 russian-full을 편집) 재료 zip 또는 결과/의 zip에서 꺼내 쓴다.

3. 한 장 만들 때 (작업 한 줄 = 그림 한 장)
 - prompt_en을 그대로 쓴다(공통 그림체 문장 포함, 줄이거나 바꾸지 않는다). 기준표(style-guide.png)와 '참고' 그림을 함께 넣는다. 연속 동작은 그 친구의 full·model을 꼭 함께 넣는다.
 - '방법'이 편집이면 '원본' 그림을 고쳐서 만든다(새로 그리지 않는다).
 - 크기·배경은 주문서대로. 안 되면 같은 비율의 가장 큰 크기, 투명이 안 되면 적힌 단색(그림자·번짐·질감 없이 완전히 한 색).
 - 스스로 검사: 주문서 '확인' + 글자·숫자·로고 없음 + 잘린 곳 없음 + 기준표와 같은 그림체 + (친구) 원문 생김새·사용자 사진과 털색·무늬·눈 색. 틀리면 한 번만 다시 만든다(-v2). 그래도 틀리면 그대로 두고 기록한다.
 - 파일 이름 = 주문서 file(다시 만든 것은 -v2). 시트는 '칸'을 '칸_json' 이름의 JSON 파일로도 만든다.

4. 저장 (그림 5장마다, 그리고 실행을 끝낼 때 꼭)
 - 새로 만든 그림을 zip 하나로 묶는다: 이름 '결과-<묶음>-<첫순번>~<끝순번>-<YYYYMMDD-HHMM>.zip'(한국 시각).
   zip 안 경로는 주문서 '받는_곳' 그대로(예: art-src/1-pets/russian-body.png). 납품 기록(만든 파일·실제 크기·다시 만든 것·어색한 것)을 art-src/<묶음>/납품-<YYYYMMDD-HHMM>.md로 같이 넣는다.
 - zip을 결과/ 폴더에 올린다. 결과/에 못 올리면 내 드라이브 맨 위에 같은 이름으로 올린다.
 - 이어서 '완료목록-<YYYYMMDD-HHMM>.txt'를 결과/에 새로 올린다(형식은 '01 완료목록'과 같게): 지금까지 끝난 작업 전체 + 다음 작업 + 보류·실패 메모.
 - 기존 파일은 고치거나 지우지 않는다(항상 새 파일). 올린 뒤 결과/에 실제로 있는지 확인한다.

5. 한도·멈춤
 - 이미지 생성 한도(429 등)에 걸리면: 그때까지 만든 것을 4번대로 저장하고, 완료목록에 '한도 도달 · 다음 작업 <묶음> <순번> <file> · 풀리는 시각(알면)'을 적고 이번 실행을 끝낸다.
 - 다음 예약 실행(6번)이 다시 시도한다. 사람에게 묻지 않는다.

6. 자동 이어하기 (예약)
 - 매시간 반복하는 예약 작업 1개가 있게 한다. 내용: "구글 드라이브 「한글나라 그림 작업 (GPT·Claude 공용)」의 최신 '00 작업지시'대로 이어서 그림 작업".
 - 예전 한글나라 그림 예약(다른 대화의 '매시간 자동 이어하기')이 있으면 끄고 이것 하나만 둔다(둘이 같은 그림을 겹쳐 만들지 않게).
 - 주문서 0~9가 모두 끝나면 완료목록에 '전체 완료'를 적고 예약을 끈다.

7. Claude → GPT 알림 (Claude가 새 판에서 고친다)
 - 1-pets 1~82의 정본은 컴퓨터에서 만든 그림(재료2·3·4)이다. 예전에 클라우드가 만든 1-pets 40~44·53~66(zip)은 쓰지 않는다.
 - 2-items 1~7(앞모습 시트 sheet-01~07)은 예전에 클라우드가 만든 것이 정본이다: 내 드라이브 맨 위 '2-items-정면01~07-검사기록포함.zip'. 옆모습 시트(8~14)는 이것을 참고로 같은 아이템·같은 칸 순서로 그린다.
 - 다시 그릴 것: 없음.

8. 하지 않는 것
 - 재료·작업지시·예전 파일을 지우거나 고치지 않는다(결과/에 새 파일만 더한다). git·GitHub·앱 코드(source/, art/)는 건드리지 않는다(Claude 몫).
 - 아이·가족 이름을 파일·그림·기록 어디에도 쓰지 않는다.
 - 질문하지 말고 끝까지 진행한다. 설명은 한국어로 짧게.
